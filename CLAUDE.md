# Stock System

## IMPORTANT: This is a PUBLIC GitHub repo
Repository: `Amati-Lee/stock-system`
Deployed to: Cloudflare Pages (https://stock-viewer-11m.pages.dev)

## Tech Stack
- Python scripts: stock screening, OHLC download, institutional data, AI analysis
- PWA output generated by `generate_pwa.py` into `pwa/` (gitignored, deployed separately)
- Cloudflare Pages for PWA hosting, Workers for watchlist KV
- GitHub Actions: daily pipeline at 15:30 Taiwan time
- Dependencies: `requirements.txt`, `python-dotenv`, `anthropic`

## Security Rules

### Sensitive Information
- ALL API keys/tokens MUST be in `.env` (gitignored) or environment variables
- Required secrets: `ANTHROPIC_API_KEY`, `CLOUDFLARE_API_TOKEN`
- GitHub Actions uses Repository Secrets (Settings > Secrets)
- NEVER hardcode tokens in `.py`, `.bat`, `.yml`, or any tracked file
- Historical lesson: Cloudflare token `7NRf_...` was once committed and had to be revoked

### Before Every Push
1. Run `git status` to verify `.env` is NOT staged
2. Run `git diff --staged | grep -i "sk-\|api_key\|token\|secret"` to catch leaks
3. Confirm `pwa/` is not staged (it's gitignored, regenerated by pipeline)
4. Review `git diff --staged` for any accidental secrets

### Pipeline Order
- download_ohlc > download_institutional > stock_system > stock_analyze > generate_pwa
- download_ohlc must preserve fi/ti/di columns when merging
- Do not re-run AI analysis locally if Actions already ran (avoids double billing)
